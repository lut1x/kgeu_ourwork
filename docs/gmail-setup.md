# Реальная отправка кодов через Gmail

1. Включите [двухэтапную проверку Google](https://myaccount.google.com/security).
2. Откройте [пароли приложений](https://myaccount.google.com/apppasswords) и создайте пароль для `Tech Monitor`.
3. Из корня проекта выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Configure-Gmail.ps1
```

Команда попросит полный адрес Gmail и пароль приложения. Пароль вводится скрыто, сохраняется в игнорируемом Git файле `.env.local` и не выводится в консоль. Команда применит настройки backend, проверит SMTP-аутентификацию и перезапустит nginx. Она не отправляет тестовые письма самостоятельно. После успешной настройки зарегистрируйте свой адрес в приложении и проверьте реальную доставку кода, в том числе папку «Спам».

Используется `smtp.gmail.com:465` с TLS и проверкой сертификата, `MAIL_MODE=smtp`. Mailpit может продолжать работать как локальный инструмент, но backend больше не отправляет туда письма.

Обычный пароль Google здесь не используется. Если страница паролей приложений недоступна, причиной может быть политика организации, Advanced Protection или способ настройки двухэтапной проверки. [Официальная инструкция Google](https://support.google.com/mail/answer/185833?hl=ru).

При переносе на сервер смените `APP_URL` на внешний HTTPS-адрес, задайте `COOKIE_SECURE=true` и перенесите существующий ключ шифрования вместе с БД через защищенное хранилище. [Настройки SMTP Google](https://support.google.com/a/answer/176600?hl=ru).
